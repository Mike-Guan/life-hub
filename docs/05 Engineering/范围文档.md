# 范围文档

> 按 AI-native 指南，开工前写清楚：做什么、故意不做什么、要什么证据才加功能。依据 [[Hub PRD]] 第 7 节和 [[技术架构]] 第 10、14 节。

## M0（第一个 PR）做什么

- 仓库、CLAUDE.md、docs/ 里的项目文档
- SwiftUI 多平台工程（iOS + Mac），共享包 HubCore、CompanionKit
- 数据契约：`ModeChange`、`ModeLog`、`WidgetSnapshot`（带 schemaVersion、id、updatedBy、deletedAt），单元测试
- iOS 和 Mac 首页：RUNNER companion（先用设定稿的静态图加 SwiftUI 动画，`runner.riv` 做好后换 Rive）、4 个 mode 一键切换、今天的 mode 时间轴
- Mac 菜单栏：当前 mode 图标，点开能切换
- 数据先存本机 JSON 文件；能在模拟器里跑，不需要 iCloud 权限

## 故意不做（M0）

- iCloud 同步（等确认 Apple Developer 付费账号）
- 小组件、锁屏、控制中心按钮（下一个切片）
- Rive（等 Mike 在 Rive 里做出 `runner.riv`）
- 地点 / Focus / 日历自动切换、HealthKit、energy（M1 之后）
- 晚间记录、副业工具、任何 AI 调用
- 界面上不放没接好的按钮

## 接下来（按 PRD v2 的交付顺序）

1. **M1a iOS 被动闭环**：公司和拳馆围栏 + 工作日时间表自动切、HealthKit 睡眠 → energy、锁屏和桌面小组件、手动纠正。
2. **M1b 同步 + Mac**：iCloud 同步，两台真机验证；Mac 菜单栏和总览面板接真实数据。
3. **M1c Mac 副业工具**：内容日历、手动参考库、传送门。

## 加功能要的证据

- 每个切片 Mike 自己用满一周，一周后仍主动打开，才做下一个切片
- 同步只在 iPhone + Mac 两台真机上验证过才算完成
- 证据分三级，不混着说：能编译 / 两台真机本地验证过 / TestFlight 装上用过

## 停止或缩减条件

- M1 用两周，Mike 每天主动切 mode 少于 1 次，且自动切也没让他觉得有用 → 停下来重新讨论
- 某个功能用一周后没再碰 → 从界面上拿掉
- Rive 在 Mac 菜单栏常驻 CPU 占用明显 → 菜单栏用静态图
