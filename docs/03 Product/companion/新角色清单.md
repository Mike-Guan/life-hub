# 新角色清单

加一个新角色（像 KURO 这样的预设角色）时，按这份清单从头走一遍。参照物是 HAKU：HAKU 有的每一项，新角色要么做出来，要么写明"这项不做"和原因。
KURO 是第一个照着做的角色，她漏掉的地方都记在最后一节，下次别再漏。

## 0. 先定再做

- [ ] 人设、外形、每个模式的造型先出预览，Mike 批准后再写代码。
- [ ] 动作表：对照下面第 2 节逐项列出"沿用 HAKU / 改 / 新画 / 不做"，一起给 Mike 看。
- [ ] 台词表：每个台词池都要有她自己的版本（见第 3 节）。
- [ ] 隐私：如果角色原型是真人，仓库里只写"第 N 个预设角色"，不写名字、学校、作息、地点、关系。真人的具体设置放进 App 设置，在她自己的手机上填。
- [ ] 开一个 Issue 写清范围、不做什么、测试计划。

## 1. 数据和接口（工程）

- [ ] `Persona` 加一个 case，默认仍是 HAKU。
- [ ] 模式对应：`Mode.title(for:)`、`tagline(for:)`、`code(for:)`、`symbol(for:)`、`color(for:)` 都给出她的版本。英文代号（如 TENNIS / DESK）和卡片颜色要和预览一致。
- [ ] 她的 Look 枚举和 `Look(mode:)`，模式到造型的对应只放这一处。
- [ ] 视图入口和 HAKU 对齐：`XxxView` 的参数尽量和 `CompanionView` 一样（`event`、`onTap`、`style`、`showsBubble`、`wearing` 等），`XxxPortrait` 对齐 `CompanionPortrait` 的 framing。缺的参数要在 Issue 里列出来。
- [ ] 商城：她自己的商品和纪念品（`ShopItem.persona`）、她自己的衣柜（每个角色单独存）、开箱按角色过滤。
- [ ] 进度按角色分开（2026-10-07 定）：能量罐、商品、纪念品、房间痕迹、体能元气各算各的；生活记录、睡眠、每周回忆卡共用。新角色从零开始，切换前弹一次确认。新角色要接进 `CanLedger.only(_:)` 和 `GrowthStore.persona`。
- [ ] 换角色时：重新读衣柜，刷新小组件、手表、通知（睡前、下班、邀请）、倒计时。
- [ ] 截图参数能画出她：`-screenshot-persona`、`-screenshot-wearing`。

## 2. 动作和画面（UI）：对齐「状态」，不对齐「动作」

**原则（Mike 2026-10-07 13:54Z 提，PM 同意）**：每个角色的动作池跟着人设变，不用照抄 HAKU 的动作；要求只有两条：
1. **状态全覆盖**：HAKU 能进入的每一个状态和切换（下面每一行就是一个「槽」），新角色都要有自己的画面，不能只换台词泡，也不能空着。具体演什么由人设决定（HAKU 吃零食，KURO 可以织东西；HAKU 推耳机，KURO 可以推眼镜）。
2. **数量接近**：每一类（待机小事、点击反应、手表戳一下、房间痕迹、一次性动画）的数量和 HAKU 相同或接近（相差不超过约两成）。
- 兜底：某个槽暂时没画，用该角色自己的通用反应（弹一下 + 换表情），**绝不显示 HAKU 的画面，也不能只剩台词泡**。
- 结构上靠 UI 草稿 §3 的「舞台」：`CompanionView` 只管什么时候播哪个槽，每个角色只提供每个槽怎么画。

下面每一行是一个槽，结论写：她的版本是什么 / 用通用兜底（写原因）。

**点一下**
- [ ] 点击有身体反应（弹一下、换表情），不能只换对话泡。
- [ ] 连点 5 次会转身不理人。
- [ ] 睡觉、打盹时点击有特殊反应（翻身）。
- [ ] 点击能跳过正在播的回来动画、洗澡等一次性场景。
- [ ] 首页传了 `onTap`（HAKU 用它切副业状态；新角色不需要也要写明）。

**待机**
- [ ] 眨眼、呼吸、按精力调快慢。
- [ ] 待机小动作（HAKU：打盹、玩手机、吃零食、画画、练习、收拾）。
- [ ] 沙发阶段 / 偷看（HAKU 的 couch stage）。
- [ ] 有台词池就要有触发它的状态，不能留"写了但永远不出现"的台词。

**状态和场景**
- [ ] 需要（久坐、刷手机等）：姿势变化，不只是换台词；`needSince`、邀请时跳一下。
- [ ] 活动场景：走路、洗澡、Daily 提示、加班等，每个都有姿势。
- [ ] 房间痕迹、隐藏数值（体能/元气）的外观变化。
- [ ] 精力表情：睡眠 <6h / 6-7.5h / >7.5h 三张脸。

**一次性动画**
- [ ] 庆祝（赢了、做完计划的事）、下班、宅家、伸懒腰、复活、加油（cheer）。
- [ ] 回来的时候（3-7 天 / ≥8 天 / 没数据），或写明只给 HAKU。
- [ ] 开箱：首页、开箱页都能播。
- [ ] 晚安动画；通知里的循环短版。

**手表**
- [ ] 戳一下有几种反应、各有台词，戳太多会转身，轻震。
- [ ] 表盘小组件三种尺寸都画她。

## 3. 台词（PM）

- [ ] 首页点击：按模式、需要、待机、活动、时刻。
- [ ] 锁屏台词、通知文案（睡前、下班、邀请、暂停提醒）。
- [ ] 开箱：普通商品一句、纪念品一句。
- [ ] 商城横幅、衣柜分类名、奖励名（如"网球日"代替"周日拳击"）。
- [ ] 回来的时候、庆祝等一次性动画的台词。
- [ ] 所有写着"HAKU"的文案改成 `persona.title`。

## 4. 每个界面都要出现（QA 矩阵）

装机前 QA 对每个角色 × 每个模式逐格看：

| 界面 | 要看什么 |
|---|---|
| 首页卡片 | 颜色铺满无白边，造型对，点击有动作 |
| 模式按钮、TODAY 时间线 | 她的颜色和代号 |
| 首页标题、副标题 | `XXX MODE` 用她的代号，没有 HAKU 专属内容（如副业行） |
| 商城、衣柜、开箱 | 她的商品、图标、试穿、开箱动画 |
| 锁屏小组件 | 头像、穿戴、台词 |
| 主屏小组件、控制中心 | 颜色、图标、名字 |
| 手表 App、表盘小组件 | 画的是她，戳一下有反应 |
| 通知（含扩展画面） | 文案和画面都是她 |
| 回来的时候、庆祝 | 按设计播或明确不播 |
| 换角色 | 以上全部立刻跟着变 |

## 5. KURO 的教训（2026-10-07）

- 第一次装机时商城、衣柜、开箱还是 HAKU 的东西：做角色时没把商城算进范围。
- 卡片背景白边、模式颜色和代号还是 HAKU 的：没有逐个界面检查。
- 备课模式出现 HAKU 的副业文案、换角色后小组件和通知没刷新：只改了首页。
- 点 KURO 几乎没动作，只换对话泡：动作表只做了造型和表情，没对照 HAKU 的点击反应。
- 她的待机和偷看台词写好了但永远不出现：台词和触发状态分开做，没人对上。
- 规则：以后每个新角色都先填完这份清单再开工，QA 用第 4 节的矩阵验收。
