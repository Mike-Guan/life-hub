# Life Hub 方向

> 2026-10-02 Mike 定下的新方向，**取代** [[个人项目计划]] 和 [[MVP 计划草稿]] 里与之冲突的部分。以下是 Mike 原话的整理，细节之后再讨论。

## 一句话

一个 Mike 自己用的 hub，用来管理生活。设计要很酷，有 **iOS 端和 Mac 端**，companion 的状态映射 Mike 的状态。

## Companion 模式（Mike 举的例子）

| 模式 | 场景 |
| --- | --- |
| 上班 mode | 工作日上班时间 |
| 下班 chill mode | 买菜、看剧、健身 |
| 拳击日 mode | 拳击训练日 |
| 副业 make money mode | 做 [[副业 - 东京人像摄影账号]] 和 [[副业 - 照片生成短片账号]] |

可以手动切换模式。companion 的形象、带情绪价值的 UI 和动画是重点。

## 两端分工

- **iOS 端**：和之前讨论的一样，学习和检测 Mike 的状态，给情绪价值。之前的状态模型（Energy × Load）、默认沉默、最小动作等思路仍可沿用，见 [[MVP 计划草稿]]。
- **Mac 端**：除了 hub 本身，在副业模式下提供技术支持，例如：
    - 爬取其他账号的案例做参考
    - 定期发布内容
    - 管理和分析账号流量数据
    - 其他功能按需求再讨论
